# Generator savjeta

Ova jednostavna React aplikacija dohvit statusaća i prikazuje nasumične savjete s [Advice Slip API](https://api.adviceslip.com/).

## ✨ Značajke

- Dohvaća nasumični savjet prilikom učitavanja stranice
- Omogućuje korisniku da dobije novi savjet klikom na gumb
- Broji koliko je savjeta korisnik pročitao
- Koristi React hookove: `useState` i `useEffect`

## 🚀 Tehnologije

- React (Vite ili Create React App)
- JavaScript (ES6)
- Fetch API

## 📚 Napomene

Ovaj projekt napravljen je kao jednostavna vježba za učenje React-a, s ciljem da se vježbaju osnovni koncepti kao što su hookovi i rad s asinkronim operacijama.  
Projekt je jednostavan, ali pruža dobar temelj za daljnje učenje i proširivanje funkcionalnosti.
